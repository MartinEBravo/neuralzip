# Four-model training trajectories

This directory combines the final GPT-2 and BERT Base WikiText-2 checkpoint
results with the ResNet-18 and ResNet-34 CIFAR-100 results.  The canonical CSV
and 2x4 figure are generated by `examples/render_four_model_training_suite.py`,
which requires complete verified compressor pairs for every epoch before
writing the artifacts.

# Paper results

The outdated saved-results archive and ResNet101-only supplement have been removed.
Their original bytes remain backed up outside this repository. The complete final
paper evidence is not yet packaged here; saved-result checks and exports are
unavailable until that evidence is installed.

`paper/catalogue.json` retains pinned input identities and tensor manifests used
by the reproduction scripts. It is configuration, not a results snapshot.
Fresh outputs go under `scripts/results/reruns/` (ignored by Git).
